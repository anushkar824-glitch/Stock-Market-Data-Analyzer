
# MarketScope – Stock Market Data Analyzer

A full-stack stock market analytics platform built using Python, FastAPI, Next.js and SQLite.

## Project Overview

MarketScope helps users explore historical stock market data, analyze technical indicators, monitor watchlists, track simulated portfolios and evaluate trading strategies through backtesting.

## Key Features

- Historical stock market data using Yahoo Finance
- Stock price charts and market summaries
- Technical indicators: SMA, RSI, MACD and Bollinger Bands
- Daily returns and volatility analysis
- Stock watchlist management
- Simulated portfolio tracking
- SMA crossover strategy backtesting
- Configurable market alerts
- Downloadable stock analysis reports
- Interactive financial dashboard

## Technology Stack

**Backend**
- Python
- FastAPI
- Pandas and NumPy
- yfinance
- SQLite

**Frontend**
- Next.js
- TypeScript
- Tailwind CSS
- Recharts
- Lucide React

## Data Source

Historical stock market data is retrieved through Yahoo Finance using the yfinance library. Availability and freshness depend on the data provider. Historical data should not be considered guaranteed real-time exchange data.

## Disclaimer

This project is intended for educational and analytical purposes only. It does not provide financial advice, investment recommendations or broker integration. Portfolio transactions and backtests are simulated.
